1. Data Source & Column Detection

The dashboard accepts a CSV export from Microsoft Viva Insights (Copilot metrics query). Columns are detected automatically by normalizing each header to lowercase with all non-alphanumeric characters removed, then matching against regex patterns.

3. Tier Classification (L-Tiers)

Each row (user × week) is classified based on active days that week:

TierConditionDescription
L3 Expertactive_days ≥ 5User actively used Copilot on 5+ days that week
L2 Intermediateactive_days ≥ 3Moderate weekly engagement (3–4 days)
L1 Beginneractive_days ≥ 1Minimal engagement (1–2 days)
Inactiveactive_days = 0Licensed but did not use Copilot that week
if (active_days >= 5) → L3 Expert
else if (active_days >= 3) → L2 Intermediate
else if (active_days >= 1) → L1 Beginner
else → Inactive

4. Usage Segments (12-Week Rolling Window)

Each user is classified using a 12-week rolling window ending at each row's week. This captures sustained behavior, not just a single-week snapshot.

SegmentConditionsDescription
Power UseractiveWeeks ≥ 9 AND avgActions ≥ 15Consistently active with high-volume usage
Habitual UseractiveWeeks ≥ 9Consistently active but moderate volume
Novice UseravgActions ≥ 1Some usage but not yet habitual
Low UseravgActions > 0Minimal/sporadic usage
Non-useravgActions = 0No actions in the 12-week window
window = last 12 weeks of data for this user (or fewer if less history)
avgActions = sum(total) across window / window.length
activeWeeks = count of weeks where total ≥ 1
isHabitual = activeWeeks ≥ 9

if (isHabitual AND avgActions ≥ 15) → Power User
else if (isHabitual) → Habitual User
else if (avgActions ≥ 1) → Novice User
else if (avgActions > 0) → Low User
else → Non-user
The 12-week window is per-person. If a user only has 6 weeks of data, the window is 6 weeks. The window slides forward with each row chronologically.

5. Loyalty & Churn Analysis

For each week, users are classified by comparing their activity against the prior 4 weeks:

CategoryDefinition
New UsersActive this week but never active in any of the prior 4 weeks
Loyal UsersActive this week AND active in all of the prior 4 weeks
Churned UsersActive in at least one of the prior 4 weeks but not active this week
For each week W:
activeNow = set of PIDs with total > 0 in week W
priorWeeks = 4 weeks immediately before W
everPrior = set of PIDs active in ANY of priorWeeks
allActivePrior = set of PIDs active in ALL of priorWeeks

New Users = activeNow − everPrior (active now, never before)
Loyal Users = activeNow ∩ allActivePrior (active now AND all 4 prior)
Churned = everPrior − activeNow (were active, now gone)

New-to-Churn (NC) Ratio

NC Ratio = New Users / max(Churned Users, 1)

Interpretation:
> 1.0 → More users joining than leaving (growth)
= 1.0 → Equal inflows and outflows (stable)
< 1.0 → More users leaving than joining (decline)

6. Health Score & Adoption Stage

The Health Score is a composite metric (0–100) combining four weighted dimensions:

Health Score = (
  (pctActive / 100) × 0.30      // Active rate contribution
  + min(pctPH / 20, 1) × 0.30   // Power+Habitual contribution
  + min(pctL3 / 25, 1) × 0.20   // L3 Expert contribution
  + min(ncRatio / 1.2, 1) × 0.20 // Retention contribution
) × 100
ComponentWeightTarget (100% contribution)What it measures
Active Rate30%100% of users activeBreadth of adoption
Power + Habitual %30%≥ 20% of usersDepth of habit formation
L3 Expert %20%≥ 25% of usersIntensity of weekly usage
NC Ratio20%≥ 1.2User retention & growth

9. Insights Tab – Detailed Calculations

Adoption Stage (Header Badge)

if (pctActive ≥ 70) → "Frontier Firm"
else if (pctActive ≥ 50) → "Developing"
else → "Early Stage"

Habit Formation Stage

if (pctPH ≥ 20) → "at Frontier Firm benchmark"
else if (pctPH ≥ 10) → "approaching Frontier Firm benchmark"
else → "below Frontier Firm benchmark"

Retention Health

if (ncRatio ≥ 1.2) → "Growing"
else if (ncRatio ≥ 0.8) → "Stable"
else → "At-Risk"

Trend Calculation

first4weeks = average weekly total actions in the first 4 weeks of data
last4weeks = average weekly total actions in the last 4 weeks of data
trendPct = ((last4weeks − first4weeks) / max(first4weeks, 1)) × 100

Progress Bar Values

pb_active = min(round(pctActive / 70 × 100), 100)
pb_ph = min(round(pctPH / 20 × 100), 100)
pb_l3 = min(round(pctL3 / 25 × 100), 100)
pb_loyal = min(round(loyalUsers / activeUsers × 100), 100)

10. Spanish Language Support

The dashboard automatically detects column headers in both English and Spanish. Column names are normalized (lowercased, all non-alphanumeric characters removed) before matching. No configuration is needed — simply upload a CSV with Spanish headers from Viva Insights.

Supported Spanish Column Names

MetricSpanish Column Header
Total ActionsTotal de acciones de Copilot realizadas
Active DaysTotal de días activos de Copilot
Chat PromptsPrompts enviados en Chat de Copilot (trabajo)
Excel ActionsAcciones de Copilot realizadas en Excel
Outlook ActionsAcciones de Copilot realizadas en Outlook
Teams ActionsAcciones de Copilot realizadas en Teams / Acciones realizadas para resumir chats con Copilot en Teams
Date column: Accepts FechaMetrica, Fecha, as well as standard English names like MetricDate, Date, WeekDate.
